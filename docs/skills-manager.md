# Skills 管理器

重启开发进程后运行 `npm run dev`，从左侧 AI → Skills 管理进入。前端页面、preload 与主进程必须来自同一次构建；只刷新旧 Electron 窗口可能仍保留旧接口。

## 导入自己的技能

点击“扫描本机” → “扫描并识别”，勾选需要的技能 → “加入技能库”。例如已安装在本机 Codex 目录中的 github-release-desktop 会以外部安装关联显示；源文件不会被迁移或删除。

也可以选择“导入技能 → 本地文件”，选择完整技能文件夹、ZIP 或 SKILL.md，再解析预览。选择本地 SKILL.md 时会一并导入同目录下的完整资源。

扫描关联的原始目录默认为只读：移除关联不删除文件。需要由管理器控制启停和更新时，安装到同一目标并明确选择“备份后替换已有目录”，将该安装纳入管理。

## 从网上安装

GitHub 支持仓库、目录和 SKILL.md 链接，可选填分支、标签或提交号。解析时锁定实际提交，下载完整目录。一个仓库包含多个技能时可多选。

其他网站需要 HTTPS ZIP 或 SKILL.md 直接下载地址；介绍网页不等于技能安装包。首版在线下载支持公共资源，私有仓库需要先下载到本地再导入。

查看候选说明和资源后，可以仅收藏到技能库，也可以同时选择 Codex、OpenCode、Antigravity IDE/桌面或 Project Hub AI，以及全局/指定项目范围。每项安装独立报告结果，失败项不会让其他成功项消失。

## 查看、更新和卸载

- 概览：作者用途说明、来源、提交或内容摘要、文件数量和 AI 解读。
- 内容：从文件列表选择 SKILL.md、引用文档、脚本等，切换 Markdown 预览/原文。二进制和大文件仅显示无法预览提示，不执行。
- 安装位置：查看每个目标及范围、实际目录、外部/管理器安装状态。支持安装、停用、启用、卸载。
- 更新与历史：检查来源并查看旧/新内容对照，更新库条目前保留上一版本，支持恢复。外部安装副本按需重新安装，不自动覆盖；副本与库版本不一致会标记。
- 更多操作：导出完整 ZIP；没有安装关联时可以删除库条目。

安装目录有本地修改时，管理器会阻止直接停用或卸载；重新安装需选择备份后替换。备份目录记录在操作历史中。库条目的“恢复上一版本”恢复库版本，安装目录的备份可从历史给出的路径取回。

Codex 与 Antigravity 可能读取同一项目 .agents/skills 目录。共享安装不能单独停用；卸载其中一个关联会保留其他关联需要的目录。目标工具的运行权限与会话刷新由该工具负责，管理器不宣称文件复制后已自动加载。

## 内置 AI

在“AI → Skills 管理”中选择一个技能，在详情“概览”下方的“使用此技能”中直接提问，无需预先启用到 Project Hub AI。可以选择项目上下文；项目详情的“Skills 管理”入口会保留项目上下文。Project Hub AI 安装关联仍可用于管理全局或项目范围的启用状态。

所有内置 AI 功能统一使用“全局设置 → AI 服务”保存的配置；侧栏不再提供独立的 AI 服务入口，旧 `/ai/services` 地址会跳转至全局设置的 AI 分类。

当前助手会把问题和选中技能正文发送给全局设置中配置的模型，提供用途解释、步骤、计划和文本草稿。没有命令执行、项目文件读写或发布工具运行器，不能在应用内自动构建或上传安装包；需要执行时交由 Codex/OpenCode/Antigravity 等实际 Agent 使用技能。

AI 解读默认只发送 SKILL.md，结果按技能版本缓存，库版本更新后失效。配置 Ollama 或 API 模型时使用普通文本调用；OpenCode 模型后端使用专用禁止工具调用的分析 Agent。

## 随安装包分发技能

项目中的 `resources/bundled-skills/` 存放要随应用分发的完整技能目录，目前已加入 `github-release-desktop`。以后可将其他允许再分发的技能文件夹复制到该目录，保留许可、署名、脚本和参考资料。

开发环境也可在技能详情名称后点击“加入随包分发”，直接复制库中的完整技能。相同版本不重复写入；遇到不同版本会提示“备份并替换”，备份保存在用户技能库并记入历史，不混入安装包。安装版没有开发项目路径，此按钮禁用，可使用“导出完整 ZIP”。

开发启动时读取项目资源目录；安装包通过 electron-builder 的 extraResources 复制到 `resources/bundled-skills`。启动时仅将新技能名称加入当前用户技能库，不自动安装到 Codex 等工具，不覆盖同名库条目，也不重新添加用户已删除的技能。更新内置技能后，已有用户需要手动导入新版；首次分发记录存放在用户技能目录的 `bundled-state.json`。

Windows 安装包构建命令：`npm run package:win`，产物目录为 `dist/`，禁用自动发布。这与仅编译源码的 `npm run build` 不同。打包内容不包含开发者 AppData 下的数据库或个人技能库。

## 验证

```text
npm run typecheck
npm run test:skills
npm run test:skills-ui
```

单元测试使用独立临时目录验证完整资源、重复导入、四目标安装、项目范围、共享目录、更新恢复、备份、外部修改保护和异常 ZIP。Electron 测试使用隔离 userData 和目标目录，验证真实 preload/IPC、SQLite 持久化及页面安装/启停，不修改真实工具技能目录。
