# 全局 Agent

任意页面右下角的 Agent 悬浮按钮打开右侧面板；项目详情自动带入项目，镜像与服务器页面带入当前选定项目/服务器。面板中的选择可以手动切换。每个任务固定其开始时的上下文，关闭面板或切换页面不会终止任务。

## 配置

全局设置 → AI 服务分为通用 AI 与 Agent AI。Agent 使用独立的 `ai_config.agent` 记录，不回退到通用配置。支持从通用 AI 复制到表单，保存后独立生效。连接测试验证结构化工具请求格式；实际任务仍依赖所选模型的规划能力。支持现有的 OpenAI 兼容接口与 OpenCode CLI；CLI 使用禁止工具执行的专用 Agent，仅产生计划，实际操作统一由应用服务执行。

## 操作

- 读取项目构建目标与已保存发布配置。
- 构建已有目标，等待真实执行结果并返回产物；项目构建区提供“交给 Agent”。
- 镜像构建、推送、部署，使用镜像与服务器页面保存的配置。
- 查询选定服务器的容器、镜像、服务状态以及容器日志。
- Git push 上传已提交代码，Git pull 下载远端代码；不自动提交、强制推送或解决冲突。
- 服务器单文件上传下载，指定项目内相对文件路径与服务器绝对文件路径；两端父目录须已存在，完成后校验文件大小，再将临时文件改名为目标文件。下载与支持 OpenSSH 原子改名的服务器可替换已存在文件。

构建、发布、Git 操作及传输都先展示具体对象和参数，点击确认后执行；配置变化会使待确认操作失效。服务器凭据仅由应用读取，不加入模型提示。当前不提供任意命令执行、代码修改、目录递归同步或服务器自动修复。

## 生命周期

任务和日志保存在本地 SQLite 的 `agent_tasks` 表。面板显示最近 100 个任务并按项目、服务器过滤；活跃的其他对象任务可以快速切换。最多执行 12 轮模型规划，历史参考使用同一对象最近三个已结束任务。

停止构建会终止对应构建进程；模型请求结束后丢弃其后续动作。已开始的服务器发布、Git 操作或文件传输会完成当前操作，停止按钮阻止后续步骤。应用退出后不自动续跑，重启会标记未结束任务为中断，需核实实际状态后重新发起。

## 验证

`npm run test:agent` 检查工具请求解析及确认策略。
`npm run test:agent-ui` 在隔离 Electron 环境及本地模型响应服务中验证全局面板、配置隔离、真实构建、日志、关闭面板后继续、拒绝操作、配置变更、运行中停止与重启中断标记。不会连接真实服务器或发布真实镜像。
